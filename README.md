📸 Site Photographie

https://focusetlumiere.fr/

Application web moderne dédiée à la mise en valeur de contenus photographiques à travers une interface élégante, fluide et centrée utilisateur.

✨ À propos du projet

Ce projet est un site vitrine de photographie conçu pour présenter des portfolios de manière immersive.
Il met l’accent sur le visuel, la performance et l’expérience utilisateur, avec une navigation simple et une mise en avant optimale des images — un élément clé pour ce type de plateforme .


🚀 Fonctionnalités
Galerie photo responsive
Interface moderne et minimaliste
Navigation fluide et intuitive
Mise en valeur des visuels (UX orientée image)
Structure scalable pour évolution future

🛠️ Stack technique
Front-end : React / Next.js
Styling : Tailwind CSS
Langages : TypeScript / JavaScript
Outils : Git, bonnes pratiques de développement moderne

🎯 Objectifs
Créer une expérience visuelle immersive
Optimiser les performances (chargement rapide des images)
Proposer une base réutilisable pour d’autres projets photo
Appliquer des standards professionnels (clean code, structure modulaire)


# Installer les dépendances
npm install

# Lancer le projet
npm run dev
